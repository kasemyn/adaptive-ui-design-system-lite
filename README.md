# adaptive-ui-design-system-lite

> **Demo project.** This package was shared for a live demo at the **React Native community meetup in London on 22 October 2026**. It is not a maintained library.

Adaptive React Native components for phones, foldables (Z Fold, Z Flip, Pixel Fold, Surface Duo), tablets and desktop windowing. Layouts respond to the window's size class and the device's fold posture, never to device type.

```tsx
import { AdaptiveProvider, TwoPane, useAdaptiveLayout } from '@fc/adaptive-ui';
```

- **Checking native setup:** `npx adaptive-ui doctor`
- **Supported:** React Native 0.76+ with the New Architecture.

See [CHANGELOG.md](./CHANGELOG.md) for what changed between versions.
